    Éditeur et hébergement

    Éditeur et directeur de la publication : Bicode_DEV, à titre personnel et non professionnel.

    Contact : par GitHub, sur github.com/Bicode-dev.

    Comme le permet l'article 6 de la loi pour la confiance dans l'économie numérique (LCEN) à un éditeur non professionnel, l'identité de l'éditeur a été communiquée à l'hébergeur, qui la tient à la disposition des autorités.

    Hébergeur du site : GitHub, Inc. (GitHub Pages), 88 Colin P. Kelly Jr. Street, San Francisco, CA 94107, États-Unis — github.com.

    Téléchargements : les versions de CoOsmos et d'Hyperespace sont publiées sur GitHub ; les premières versions de CoOsmos sont aussi sur Google Drive (Google).

    Confidentialité (RGPD)

    Ce site ne collecte aucune donnée personnelle.

    Pas de formulaire, pas de compte, pas de statistiques de visite, pas de publicité, pas de réseau social intégré. Les polices et les images sont servies avec le site : aucune requête ne part vers un autre service quand vous le lisez.

    Seul l'hébergeur traite des données techniques : comme tout serveur web, GitHub reçoit l'adresse IP et le navigateur des visiteurs, et les garde dans ses journaux pour la sécurité du service. GitHub en est responsable, selon sa déclaration de confidentialité ; ces données peuvent être traitées aux États-Unis, dans le cadre qu'elle décrit. Ce traitement repose sur l'intérêt légitime d'assurer la sécurité et le bon fonctionnement du site (article 6.1.f du RGPD).

    Quand vous téléchargez CoOsmos ou Hyperespace, c'est GitHub (ou Google, pour Google Drive) qui vous envoie le fichier, et qui voit donc votre adresse IP, comme pour n'importe quel téléchargement.

    Cookies et stockage local

    Aucun cookie, aucun traceur : pas de bandeau à accepter.

    Le site garde seulement deux petites informations dans votre navigateur, pour les fonctions que vous utilisez. Elles ne sont jamais envoyées, ni à nous ni à personne :

    NomÀ quoi il sertCombien de temps
    coosmos-langueLa langue choisie dans le menu des langues.Jusqu'à ce que vous effaciez les données du site.
    coosmos-lanceNe jouer l'animation d'ouverture qu'une fois par visite.Effacé à la fermeture de l'onglet.

    Ces informations sont nécessaires à un service que vous demandez vous-même : elles sont dispensées de consentement (article 82 de la loi Informatique et Libertés, et lignes directrices de la CNIL). Pour les effacer, supprimez les données de ce site dans les réglages de votre navigateur.

    CoOsmos et Hyperespace

    Sans télémétrie, sans compte.

    Ni CoOsmos ni Hyperespace n'envoient de données sur vous ou sur votre utilisation. Ils ne contactent Internet que pour ce qui en a besoin :

    • Hyperespace lit la dernière version publiée sur le site de CoOsmos (GitHub) et sur Google Drive, puis télécharge l'image si vous le demandez. Ce qui est sur votre clé USB reste sur votre clé et sur votre ordinateur.
    • CoOsmos cherche ses mises à jour sur le site de CoOsmos (GitHub) et sur les miroirs d'Arch Linux, met à jour les signatures de l'antivirus et règle l'heure par le réseau.
    • Les applications que vous utilisez (Firefox, Steam…) contactent les services que vous leur demandez ; la télémétrie de Firefox et de Visual Studio Code est coupée d'office.

    Ces serveurs voient votre adresse IP, comme pour toute connexion ; rien d'autre ne leur est transmis.

    Vos droits

    Le RGPD vous donne un droit d'accès, de rectification, d'effacement, d'opposition et de limitation sur vos données. Ce site n'en détient aucune ; pour les journaux techniques de l'hébergeur, adressez-vous à GitHub par sa page dédiée.

    Vous pouvez aussi déposer une réclamation auprès de la CNIL (cnil.fr) ou de l'autorité de protection des données de votre pays.
